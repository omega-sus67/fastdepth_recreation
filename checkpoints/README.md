# Pretrained FastDepth checkpoints

Put the four trusted original FastDepth checkpoints here. The authors' [repository](https://github.com/dwofk/fast-depth) links to the [MIT model directory](http://datasets.lids.mit.edu/fastdepth/results/), which timed out during setup. No checkpoint was obtained or verified, so pretrained inference is not yet ready. The upstream `main.py` indicates these may contain serialized Python models; load only trusted files and check compatibility with modern PyTorch before use. They are not interchangeable with random initializations.
