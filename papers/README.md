# Project papers

Page numbers below refer to PDF viewer pages in these downloaded versions. The [complete project plan](../docs/fastdepth_edge_ai_plan.md) connects these references to implementation and experiments; there is no requirement to read the papers cover to cover before starting.

- [FastDepth: Fast Monocular Depth Estimation on Embedded Systems](fastdepth.pdf) — Wofk et al., ICRA 2019, [arXiv:1903.03273](https://arxiv.org/abs/1903.03273). Core reference for architecture, evaluation and the original optimization ladder.
- [NetAdapt: Platform-Aware Neural Network Adaptation for Mobile Applications](netadapt.pdf) — Yang et al., ECCV 2018, [arXiv:1804.03230](https://arxiv.org/abs/1804.03230v2). Needed when implementing platform-aware pruning.
- [Depth Anything V2](depth_anything_v2.pdf) — Yang et al., NeurIPS 2024, [arXiv:2406.09414](https://arxiv.org/abs/2406.09414v2). Needed only for optional distillation or a heavy reference.

These are the three papers explicitly listed in the project plan; tool and hardware documentation may still be needed during implementation.
